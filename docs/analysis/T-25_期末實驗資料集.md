## 11/18 之後微型感測器中斷的原因

1. **排程到期：**Windows 工作排程器的收集排程當初設定「重複 30 天」，在 11/18 下午到期停止。11/24 已改成重複到 2027-01-01（`P74D`）。
2. **憑證過期：**民生公共物聯網 SensorThings API 的 TLS 憑證（`*.colife.org.tw`，Sectigo 簽發）在 **2026-11-21 23:59:59 GMT** 到期。`sta.colife.org.tw` 與舊網址 `sta.ci.taiwan.gov.tw` 用的是同一張憑證，所以兩個網址都無法通過驗證。
   - 依專案規則不關閉憑證驗證（不使用 `verify=False`），只能等國網中心更新憑證。
   - 排程會每小時重試，憑證更新後會自動恢復收集。

## 對期末的影響
