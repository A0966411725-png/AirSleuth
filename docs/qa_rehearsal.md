# 口頭問答預演（T-17）

> 作業規範寫明：「AI 可以幫你完成工作，但你必須能解釋它做了什麼、為什麼這樣設計，以及如何驗證結果。教師可針對 Architecture、DESIGN.md、論文、資料、程式碼與實驗結果進行口頭提問。」
> 這份文件依章節整理老師可能問的問題，每題附「回答要點」與「出處」。組員認領章節後，各自熟讀負責的部分；**第 0 節每個人都要會**。
> 練習方式：兩人一組，一人問、一人在 1 分鐘內回答，答不出來的題目標記起來再讀一次出處。

## 3. Deep Research

| # | 問題 | 回答要點 | 出處 |
|---|---|---|---|
| 3-1 | 五個核心思維，挑一個說明它怎麼影響設計。 | 例如「濃度不等於暴露量」：人平均 87% 時間在室內，所以 Agent 要問時段、地點、活動與停留時間，用「濃度 × 時間 × 呼吸量」估暴露。 | 03 Q1；S-034 |
| 3-2 | 台灣 PM2.5 有多少來自境外？ | 沒有單一答案。環保署估全國年平均境外約 34～40%；但冬季北部高、夏季很低，南部高污染事件以本地為主。差異來自方法、季節、地點、時間尺度。 | 03 Q2 爭論 1；S-002、S-004、S-005 |
| 3-3 | 既然微型感測器有爭議，為什麼還用它？ | 共識是不能取代測站做法規判定，但很適合看空間分布、找熱點。我們用它判斷空間型態（相對變化），絕對數值以測站校正，並附信心程度。 | 03 Q2 爭論 2 |
| 3-4 | 台灣的 PM2.5 標準是多少？跟 WHO 差多少？ | 2024 年加嚴為年平均 12、日平均 30（原本 15、35），2030 年達標；WHO 2021 指引值是年平均 5、24 小時 15。 | S-016、S-020 |
| 3-5 | 黃燈時健康成人該不該取消慢跑？ | 一般都市濃度下運動的好處遠大於空污風險，可以改時段、路線或強度，不必取消；敏感族群或有症狀再提高警覺。 | S-033；03 Q3 第 5 題 |
| 3-6 | Q3 十個問題中，你覺得最能分辨「真懂」的是哪一題？為什麼？ | 建議答第 7 題（空間型態什麼時候會判斷錯）：要能具體說出感測器稀疏、大範圍同時燃燒、地形累積、濕度同時高估，以及無法分辨境外或國內——這些只有真的理解方法才答得出來。 | 03 Q3 |

## 5. 資料與技術可行性

| # | 問題 | 回答要點 | 出處 |
|---|---|---|---|
| 5-1 | API 有什麼限制？你們怎麼處理？ | 微型感測器 API 只保留約 4～5 小時、氣象站只給最新一筆，所以用 Windows 工作排程每小時收集，存成每日檔案並去除重複；國家測站可回溯數個月，已補抓 60 天。另外兩個政府平台的憑證在 Python 3.13 會驗證失敗，我們只關閉 3.13 新增的嚴格檢查，仍完整驗證憑證。 | T-07、T-08 回報 |
| 5-2 | 資料品質如何？ | 臺中約 80% 感測器有回傳；PM2.5 沒有負值或極端值；約 0.3% 疑似卡住；濕度欄位不可靠（19% 回報 0，正常資料中 84% 回報 90～100%）。 | T-07、T-20 回報 |
| 5-3 | 你們真的抓到局部事件了嗎？ | 10/19 下午臺中西側沿海一群感測器升高，事件中心由約 18 升到 40 μg/m³，同時區域背景只從 18 升到 26；Algorithm 2 連續約 50 分鐘判為局部型。**附近的環境部沙鹿測站同時由 19 升到 32**，證明不是感測器雜訊。 | T-20、T-08 回報；投影片 14 |
| 5-4 | 那次事件的成因是什麼？ | **感測器資料無法確定成因**（工業、港區、海風都有可能），我們只描述空間型態。這也是限制之一。 | T-20 回報 |
| 5-5 | 一個感測器飆到 111，你們怎麼知道是異常？ | 它 2 km 內 27 個感測器都正常，只有自己升高；規則要求至少 2 個鄰近感測器一起升高才算局部污染，否則判為疑似感測器異常。 | T-20 回報；投影片 15 |
| 5-6 | 你們的方法有什麼弱點？ | 沒有標準答案可驗證；微型感測器只有單日資料、還沒在微型感測器上遇到區域型事件（國家測站上有候選日，但微型感測器 API 無法回補）；校正係數只來自一個下午；固定半徑無法描述約 8 km 的群聚；無法分辨區域污染來自境外或國內。 | DESIGN.md 第 12 節 |
| 5-7 | 預測做得怎麼樣？ | 國家測站 60 天、後 15 天測試：多元線性迴歸在 1、3、6 小時都比「未來 = 現在」準，6 小時 MAE 改善臺中 9%、高雄 17%。但突發的局部高峰預測不到，這正是需要微型感測器空間資訊的原因。 | T-11 回報 |
| 5-8 | 區域型事件你們有找到嗎？ | 微型感測器還沒遇到；但國家測站 60 天裡有「多站同時升高、站間差異小」的候選日，例如臺中 10/13 六站日平均都在 22.9～30.9，高雄 9/09～9/12 十二站一起升高。成因（天氣、境外或區域傳輸）**測站資料無法判斷**。 | T-21 回報 |
| 5-9 | 微型感測器準不準？怎麼校正？ | 10/19 一個下午的共置比對：微型感測器平均比國家測站低 2.7～4.2 μg/m³；用線性＋測站濕度校正，留一站交叉驗證 MAE 降低臺中 13%、高雄 54%。只有一個下午，係數還不能用；而且臺中感測器自己回報的濕度幾乎都是 100%，所以濕度改用測站或氣象站。 | T-22 回報 |
| 5-10 | 怎麼重現你們的結果？ | `pip install -r requirements.txt` → `python -m pytest -q tests`（20 個測試）→ 執行 `notebooks/` 裡的 T-11、T-20、T-21、T-22 notebook。 | DESIGN.md 第 10 節 |
