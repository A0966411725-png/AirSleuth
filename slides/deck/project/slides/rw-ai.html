AI 技術已經做到哪裡

LLM Agent

ReAct 讓 LLM 邊推理邊呼叫工具，降低幻覺 [S-035]；空品 MCP 介面事實正確性 4.78／5 [S-036]

限制：只會「查」和「畫」，不判斷原因

感測器校正

台灣 39 個感測器以隨機森林校正，RMSE 18.4 → 5.9 μg/m³ [S-041]；混合模型 RMSE 降 58～63% [S-043]

限制：只產生更準的數字，沒接到決策

局部 vs 區域的分離

小波分解把局部事件從區域背景分離，R² 最多 +0.14 [S-045]；扣除背景後以高斯過程找熱點 [S-047]

限制：離線研究工具，沒有即時解釋

PM2.5 預測

台灣測站的時空圖神經網路 [S-048]；多尺度動態 GNN 誤差再降 6.8～8.7% [S-049]

限制：越準越複雜、越難解釋

5

AI 技術分成四塊。LLM Agent：ReAct 是基礎方法，近一年已有空品領域的 LLM 系統，透過工具查即時資料，但只會查和畫。感測器校正：台灣自己就有研究，隨機森林把誤差降到原來的三分之一左右。局部與區域的分離：國外已有小波分解、高斯過程等方法，但都是離線的研究工具。預測：圖神經網路越來越準，但也越難解釋。每一塊都很成熟，但都是各做各的。
